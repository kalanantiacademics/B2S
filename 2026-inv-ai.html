Fixed Rules vs AI Model 🧩🧠

Keduanya tetap program komputer, tapi cara menghasilkan output berbeda.

🧩 Fixed Rules
Programmer writes:
IF password is correct → open Home.
Output mengikuti aturan yang kita tulis secara langsung.
🧠 AI Model
Model learns:
banyak contoh gambar → pola → prediction.
Output berdasarkan pola yang dipelajari dari data.

Simple Mental Model

A Model Is Not a Database of Answers

Model adalah hasil training yang menyimpan patterns. Saat mendapat input baru, model memakai patterns itu untuk menghasilkan prediction.

It can still be wrong — especially when the input is very different from the examples it learned from.
