Bug Hunt Strategy

Gunakan pertanyaan berikut untuk mengisolasi penyebab masalah.

Missing Trigger?

Apakah script memiliki event seperti when this sprite clicked?

Wrong Target?

Apakah code berada pada sprite yang benar?

Wrong Order?

Apakah block tersusun dalam sequence yang masuk akal?

Wrong Value?

Apakah costume, position, sound, atau message yang dipilih sudah benar?

Fix One Script at a Time

Perubahan kecil lebih mudah diuji dan dijelaskan.

Avoid

❌ Mengubah banyak script sekaligus

❌ Menebak tanpa testing

❌ Menghapus block sebelum memahami fungsinya

Use

✅ Uji satu feature

✅ Periksa satu script

✅ Perbaiki lalu retest

Remember Sprite Costumes?

Pergantian costume secara cepat dapat menciptakan ilusi gerak.

Jika next costume dijalankan berulang, sprite terlihat seperti sedang bergerak atau berubah bentuk.

Why Use a Loop?

Loop menggantikan susunan block yang sama berulang kali.

Without Loop

next costume
next costume
next costume
next costume
→

With Loop

repeat [4]
next costume

Lebih singkat, rapi, dan mudah diubah.
